어사이드 입문 가이드

A. 어사이드는 무엇이고, 어떻게 구동되나요?

어사이드(Aside)는 AI가 직접 일을 해 주는 브라우저입니다. 공식 도움말 기준으로 웹사이트, 로그인한 계정, 방문 기록, 파일을 설정한 범위 안에서 사용해 여러 단계의 작업을 처리합니다. 질문에 답만 하는 챗봇과 달리, 사용자가 쓰는 화면에서 클릭하고 입력하고 읽는 일까지 합니다.

1결과를 말한다어떤 사이트·파일로 무엇을 원하는지 적습니다
→
2브라우저에서 실행어사이드가 사이트를 열고 클릭·입력·읽기를 직접 합니다
→
3필요하면 멈춘다로그인 인증, 승인, 모르는 값은 사용자에게 묻습니다
→
4결과 확인작업 화면에서 만든 파일과 요약을 확인합니다
→
5이어서 지시고칠 점을 다시 말하면 이어서 진행합니다
브라우저(몸)와 모델(두뇌)은 따로 있습니다. 어사이드는 브라우저와 실행 도구이고, 실제로 생각하는 AI 모델은 고를 수 있습니다. 어사이드가 제공하는 모델, 이미 가입한 구독(Claude Pro·Max, ChatGPT Plus·Pro, GitHub Copilot), 개인 API 키 중에서 연결합니다. 그래서 어사이드에서 Claude 모델을 쓰는 것도 가능합니다.

B. 시작하기: 개인 계정으로 무료 가입하고 공유 Claude 계정 연결하기

① 설치와 무료 가입aside.com/download에서 PC에 맞는 설치 파일을 받아 설치합니다(지원 환경은 다운로드 페이지에서 확인). 처음 실행하면 로그인 화면이 나오며, 개인 이메일 등으로 새 계정을 만들면 무료(Free) 플랜으로 시작합니다.
② 처음 설정영문 설정 메뉴가 어렵다면 왼쪽 메뉴의 어사이드 초기 세팅에서 한글로 확인하세요. 안내에 따라 브라우저 데이터 가져오기(방문 기록·쿠키·북마크, 선택)를 하고, 비밀번호 관리자를 설정합니다. 쓰던 브라우저의 로그인 상태를 가져오면 어사이드가 바로 업무 사이트를 쓸 수 있습니다.

연결할 때 확인하세요
· 공유 계정의 로그인 정보는 이 사이트에 적지 않습니다. 운영 담당자에게 따로 받으세요.

· 연결이 끝나면 아래 2. 모델 설정 표대로 Task models를 맞춰 사용량을 아껴 주세요. 공유 계정은 전 직원의 사용량이 합산됩니다.
· Aside 크레딧은 연결한 구독·API와 별도로 관리됩니다(공식 도움말).

D. 처음 쓸 때 알아둘 점

지시는 구체적으로"결제 처리해 줘"처럼 막연하게 쓰지 말고, 어떤 사이트·계정·파일로 무엇을 만들지 적습니다. 돈·고객 정보·로그인이 걸린 일은 하지 말아야 할 행동도 함께 적습니다. 이 사이트의 간단 사용법과 프롬프트 빌더가 그 틀을 대신 만들어 줍니다.
권한은 필요한 만큼만작업을 시작할 때 권한 모드를 고릅니다. Read only는 파일을 바꾸지 않고 보기만, Guard는 허용한 폴더 안에서만 작업하고 다른 폴더는 먼저 묻고, Full access는 컴퓨터 전체를 읽고 씁니다. 처음에는 Read only나 Guard로 시작하는 것을 권장합니다(운영 안내 초안). 발송·결제·삭제 직전 확인 방식은 아래 1. 승인 방식에서 업무마다 고르세요.
메모리와 개인정보어사이드는 방문 기록과 대화·작업에서 기억을 만들 수 있습니다. Settings > Memory에서 끄거나 보관 기간(30일·90일·계속)을 바꿀 수 있습니다. 원가·급여·계약·협상 금액·개인정보는 프롬프트에 넣지 마세요.
동시 작업은 권장 2개, 최대 3개어사이드 작업은 동시에 2개까지를 권장하고, 최대 3개를 넘기지 마세요. 많이 열어 두면 멈춤·오류가 늘 수 있습니다. 끝난 작업은 정리하고 새 작업을 시작하세요(운영 안내).
작업 중 추가 지시진행 중에 새 메시지를 보내면 Queue(현재 작업이 끝난 뒤 적용) 또는 Steer(진행 중인 작업에 바로 반영)로 처리됩니다. Settings > Agents > Chat에서 방식을 고릅니다.

E. 어사이드가 멈추거나 오류가 날 때

① 동시 작업 줄이기동시에 진행하는 작업이 많으면 멈춤·오류가 늘 수 있습니다. 작업 수를 2개 이내로 줄여 보세요.
② 컴퓨터 재부팅어사이드가 멈추거나 반응이 없으면 컴퓨터를 재부팅한 뒤 다시 실행합니다.
③ 계속 오류가 나면 문의재부팅 후에도 같은 오류가 반복되면 최성민 과장에게 문의해 주세요. 직접 폴더를 지우거나 리셋하지 마세요.

아래는 최성민 과장이 문의를 받고 안내할 때 쓰는 복구 방법입니다. 데이터에 영향이 있을 수 있으니 담당자와 먼저 상의한 뒤 진행하세요. 숫자가 큰 단계일수록 영향이 큽니다.

1단계 설치 키 복구 (공식)어사이드를 완전히 종료한 뒤(작업 관리자에서 남은 Aside 프로세스도 종료), PowerShell에서 아래 명령으로 .aside 폴더에 빈 파일 repair-installation을 만듭니다. 탐색기로 만들면 .txt가 붙으니 꼭 명령으로 만드세요. 그다음 어사이드를 다시 실행하고, 로그인과 비밀번호 관리자 잠금 해제를 다시 하라고 하면 따릅니다. 대화·루틴·메모리 파일은 그대로 남습니다.
New-Item -ItemType File "$env:USERPROFILE\.aside\repair-installation"
2단계 막힌 키 정리 (공식, Windows)1단계 후에도 계속 재시작되면 공식 도움말의 "Clear a stuck key" 절차를 따릅니다. 명령이 길어 이 사이트에는 옮겨 적지 않았습니다. 공식 문제 해결 페이지 열기 ↗
3단계 .aside 폴더 리셋 (사내 경험)최성민 과장 PC에서 위 방법으로 해결되지 않아 폴더를 초기화하자 정상화된 방법입니다. 공식 안내가 아니라 사내에서 한 번 성공한 방법입니다.
① 어사이드와 관련 프로세스를 모두 종료합니다.
② 탐색기 주소창에 %USERPROFILE%를 입력해 이동한 뒤 .aside 폴더 이름을 .aside_old로 바꿉니다. (백업 복사 없이 이름 변경만 합니다)
③ 어사이드를 다시 실행합니다. 새 .aside 폴더로 처음부터 시작합니다.
3단계 전에 꼭 알아두세요
· .aside 폴더에는 대화·작업 기록, 메모리, 사용자 스킬 같은 로컬 데이터가 들어 있습니다. 리셋하면 새 폴더에서는 비어 보이고, 다시 로그인과 초기 설정이 필요할 수 있습니다.
· 되돌리려면 어사이드를 종료하고, 새로 생긴 .aside 폴더를 다른 이름으로 바꾼 뒤 .aside_old를 다시 .aside로 바꿉니다.
· .aside_old는 며칠 정상적으로 써 보고 문제가 없을 때 삭제하세요. 그 전에는 복구용으로 남겨 둡니다.
· 작업이 멈춘 경우(승인 대기, 방향 이탈)에는 리셋하지 마세요.

출처: 1·2단계는 어사이드 공식 도움말(Troubleshoot Aside), 3단계는 사내 경험입니다. 맥은 %USERPROFILE%\.aside 대신 ~/.aside 폴더입니다. 담당자가 해결하지 못하면 어사이드 지원팀(support@aside.com)에 시각, 증상, 오류 메시지, 그날의 로그 파일(.aside\logs\daemon-날짜.log)을 보냅니다.

어사이드 가이드

어사이드를 처음 쓰는 분을 위한 기본 흐름입니다. 어사이드가 무엇인지, 가입과 공유 Claude 계정 연결, 요금제와 루틴은 업무 시작 전 확인사항의 입문 가이드에서 안내합니다.

1

어사이드 열기

브라우저 오른쪽 사이드바에서 어사이드를 열고, 업무에 필요한 페이지(FLOW, 구글 시트 등)를 함께 열어둡니다.

2

빌더로 프롬프트 만들기

프롬프트 빌더에서 기능을 고르고 항목을 채운 뒤 만들어진 프롬프트를 복사합니다.

3

어사이드에 붙여넣기

복사한 프롬프트를 어사이드 입력창에 붙여넣고 실행합니다. 첨부자료는 열려 있는 탭 기준으로 읽습니다.

4

결과 확인·최종 판단

수치·법령·광고 표현은 사람이 최종 확인합니다. "확인 필요"로 표시된 값부터 점검하세요.

5

자산 등록

잘 되는 프롬프트는 자산으로 등록해 두고, 다음에는 '다시 만들기'로 불러옵니다.

⚠️ 프롬프트·결과 요약에 원가·급여·계약·협상 금액을 넣지 마세요. 타사 브랜드명·비교 표기는 금지, 수치는 성적서 근거만 사용합니다.
