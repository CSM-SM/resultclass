STEP 01
카피 작성할 AI 툴을 고르세요
어떤 툴이든 이미지·레이아웃은 Canva에서 만듭니다. 카피 스타일에 맞는 툴을 선택하세요.
카피 작성 툴 선택
ChatGPT
✓
무료
가장 대중적. 구조적인 카피 작성에 강함. 처음이라면 추천.
Claude
무료
자연스럽고 긴 문체에 강함. 감성적인 브랜드에 추천.
Gemini
무료
구글 AI. 최신 트렌드 반영 카피에 강함.
⭐ 추천
Grok
무료
카피 + 이미지 생성 동시 가능. 결과물 빠르게 확인할 때 추천.
💡 2가지 툴, 이게 전부입니다
AI 툴 (ChatGPT·Claude·Gemini·Grok) → 카피 텍스트 생성
Canva → 이미지 만들고 카피 넣어서 상세페이지 레이아웃 완성
복잡하게 생각하지 마세요. 이 2가지만 쓰면 됩니다.

STEP 02
상품 정보를 입력하세요
입력한 내용이 다음 단계 AI 프롬프트에 자동으로 채워집니다.
상품 기본 정보
상품명 & 브랜드명 필수
예: 제로슈가 그래놀라바 / 브랜드: 헬시스낵
핵심 특징 3가지 필수
예: 설탕 0g, 단백질 15g 함유, 글루텐 프리
타겟 고객
예: 다이어트 중인 30~40대 직장인 여성
가격 & 용량
예: 15,000원 / 30개입 / 1개월치
경쟁 제품과의 차별점
예: 타사 대비 칼로리 30% 낮음, 천연 재료만 사용
원하는 톤 & 분위기
예: 고급스럽게 / 친근하게 / 감성적으로
📸
제품 사진 첨부 (선택)
첨부하면 카피 프롬프트 + Canva 이미지 프롬프트에 제품 특성이 자동 반영됩니다.
📷
사진 드래그 또는 클릭해서 첨부
JPG, PNG, WEBP · 최대 10MB
✅ 사진 첨부 완료
📊 분석된 이미지 정보
🔗
참고 상세페이지 URL (선택)
마음에 드는 상세페이지 URL을 넣으면 그 스타일이 카피 프롬프트에 자동 반영됩니다.

STEP 03
AI로 카피를 작성하세요
버튼을 누르면 프롬프트가 복사되고 AI 툴이 열립니다. Ctrl+V로 붙여넣기만 하면 됩니다.
✅ 내 상품 정보가 프롬프트에 자동 반영됐습니다
버튼 클릭 한 번으로 → 프롬프트 자동 복사 + AI 툴 새 탭 열기
완성 카피 프롬프트 (자동 완성)
작성 + 다듬기 조건이 한 번에 포함돼 있습니다. 이 프롬프트 하나만 붙여넣으면 됩니다.
내가 입력한 내용
URL 분석 내용
AI 채팅창에 Ctrl+V → 전송 완료
프롬프트 하나에 작성 + 다듬기 조건이 모두 포함됩니다
결과가 마음에 안 들면 "다시 써줘" 한 마디면 OK
같은 채팅창에서 "더 임팩트 있게", "좀 더 친근하게" 등 추가 요청만 하면 됩니다
완성된 카피 복사해두기
다음 단계(Canva)에서 붙여넣을 텍스트를 미리 복사해두세요

STEP 04
Canva AI로 이미지를 만드세요
버튼을 누르면 이미지 프롬프트가 복사되고 Canva AI가 열립니다. 이미지를 만들고 5단계에서 카피와 합칩니다.
버튼 클릭 → 이미지 프롬프트 자동 복사 + canva.com/ai 열기
Canva AI 이미지 프롬프트 (자동 완성)
💡 영어 프롬프트가 더 좋은 결과를 만듭니다.

마음에 드는 이미지가 나올 때까지 여러 번 생성해보세요

STEP 05
카피 + 이미지를 합쳐서 완성!
각 단계 버튼을 순서대로 클릭하면 됩니다. 텍스트 설명 없이 바로 실행할 수 있어요.
01
상세페이지 템플릿 고르기
Canva 상세페이지 템플릿 모음이 바로 열립니다
02
3단계 카피 복사 → 텍스트 칸에 붙여넣기
헤드라인 → 서브 헤드라인 → 혜택 → 본문 순서로 배치
03
4단계 이미지 Canva에 업로드 → 배치
왼쪽 메뉴 "업로드" → 다운받은 PNG 올리기 → 드래그로 배치
04
레이아웃 최종 조정
글자 크기·색상·여백 드래그앤드롭으로 자유롭게 수정
Canva 내에서
05
PNG 다운로드 → 쇼핑몰 등록
Canva 우측 상단 "공유" → "다운로드" → PNG → 스마트스토어·쿠팡
완성!
